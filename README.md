# Kainos — Helado Artesanal

Landing page para **Kainos | Helado Artesanal**, una heladería artesanal con café, té y pastelería.

## Cómo ver el sitio

Abrí `index.html` en el navegador o serví la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8080
```

Luego visitá [http://localhost:8080](http://localhost:8080).

## Estructura

- `index.html` — Página principal con todas las secciones
- `css/styles.css` — Estilos, paleta de colores y diseño responsive
- `js/main.js` — Animaciones de scroll y menú móvil

## Secciones

1. **Hero** — Presentación con navegación y CTA principal
2. **Tradición que se disfruta** — Historia de la marca desde 1980
3. **Pequeños rituales** — Helado, tés, café y pastelería
4. **Encontranos** — Locales con fotografías
5. **Tu pausa te espera** — CTA final y footer
